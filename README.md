# Unreal Agility Arena: AI Framework
## An AI Gym for the Unreal Engine 5

[![Video Showcase](https://img.youtube.com/vi/qKL6xmDoVCM/maxresdefault.jpg)](https://www.youtube.com/watch?v=qKL6xmDoVCM)

## About 📖
This project was built following the book "Artificial Intelligence in Unreal Engine 5" by Marco Secchi (Packt Publishing, 2024).
It covers the core AI framework in UE5, including:

Navigation System & NavMesh
Behavior Trees & Blackboards
AI Perception System
Environment Query System (EQS)
State Trees
Mass Entity Framework
Smart Objects

## Installation ⚙️

1. **Clone the repository**
```bash
   git clone https://github.com/flaz89/UE_AgilityArena_AI.git
```

2. **Generate project files**
   - Right-click on the `.uproject` file
   - Select "Generate Visual Studio project files"

3. **Build and Run** ▶️

   **Visual Studio 2022:**
   - Open the `.sln` file
   - Set the build configuration to `Development Editor`
   - Build the solution (`Ctrl+Shift+B`)
   - Run the project (`F5`)

   **JetBrains Rider:**
   - Open the `.uproject` file directly
   - Build and run from Rider
